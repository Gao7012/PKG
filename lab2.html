📄 Документация и пояснения к характеристикам

Имя файла — исходное имя файла, полученное из объекта File браузера.

Размер изображения (пиксели) — ширина и высота растрового изображения. Берётся из заголовка файла/EXIF-метаданных.

DPI (dot/inch) — физическое разрешение для печати, хранится в EXIF. Если отсутствует — «не указано».

Глубина цвета — количество бит на пиксель, определяет максимальное число цветов изображения. Из заголовка/EXIF.

Сжатие — алгоритм сжатия: JPEG (потеря), PNG (Deflate без потерь), PCX (RLE), TIFF (разные методы), BMP без сжатия.

Дополнительная информация (доп. баллы):
• JPEG: наличие квантовой таблицы;
• GIF: количество цветов в палитре;
• PCX: версия формата, число цветовых плоскостей.


Использованная внешняя библиотека: ExifReader.js (чтение EXIF, IPTC, метаданных JPG, PNG, GIF, TIFF, BMP).
Формат PCX парсится вручную через чтение 128-байтного заголовка бинарного файла, библиотека не поддерживает PCX нативно.

Поддерживаемые форматы: jpg, gif, tif, bmp, png, pcx.
